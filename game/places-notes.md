# Landmark pool

24 places: eight each from California, Norway and Nepal. Four hand-curated difficulty tiers run from recognizable silhouettes to less familiar landmarks. These are game-design estimates, not measured recognition rates; local knowledge will change what feels hard.

Each place keeps its name, aliases, region, country and reference description on the server. Only the current describer receives the name. Guessers see a rendered image and the broad three-region pool. Names and country are revealed with the scores.

Descriptions are original concise visual briefs for stylized drawings, not architectural surveys. Matching accepts the curated name and aliases with Unicode-aware case/spacing/punctuation normalization. It does not ask an AI to judge guesses.
